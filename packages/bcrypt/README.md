# Vaden BCrypt

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://opensource.org/licenses/MIT)

**Vaden BCrypt** is the official implementation of the BCrypt algorithm for the **VADEN** framework. Developed by [**cthiagoodev**](https://github.com/cthiagoodev) from the **Mobile Devs Ceará** community, this package provides a secure and efficient solution for password hashing and verification, seamlessly integrated into the VADEN ecosystem.

---

## Features

- 🛡️ **Secure password hashing**: Uses the BCrypt algorithm, known for its resistance to brute-force attacks.
- 🔒 **Password verification**: Safely compares plain-text passwords with stored hashes.
- ⚙️ **Adjustable cost**: Allows you to define the number of iterations to enhance security.
- 🧂 **Random salt**: Generates unique salts for each hash, ensuring greater security.
- 🚀 **Native integration**: Designed to work seamlessly with VADEN.
